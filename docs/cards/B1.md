## Implement

- [ ] Add a local PostgreSQL 18 compose service, a persistent development volume, raw SQL migrations, and a parameterized pg adapter. Add the migrate command through your root dependency ownership.
- [ ] Create durable jobs and results with immutable input, registry identity, cutoff, token hash, state, lease ID/owner/expiry, optional frozen run, and terminal timestamps. Never log exact farm inputs or capabilities.
- [ ] Implement create/get/delete/claim/renew/freeze/complete/fail with atomic claim and stale-lease rejection. Reclaim expired leases. Freeze once and reject changed manifests. Terminal writes are atomic.
- [ ] Create GET catalogue, POST plans, GET plans/{jobId}, and DELETE plans/{jobId}. Use the HTTP contract in docs/contracts.md, validate input size/schema and reject self-intersecting or unsupported polygon topology, and require the capability header for job reads/deletion. Unknown IDs and wrong tokens both return 404.
- [ ] Generate at least 128 random token bits and store only their hash. Add request limits and implement JobStore.purgeExpired(now) for terminal-result expiry after 24h. Same input hash never grants access to another job.
- [ ] Replace the client transport stub with HTTP adaptation. Do not call NASA or calculate in the request handler. Missing database configuration returns an explicit unavailable error.

## Done when

- [ ] Real PostgreSQL tests prove concurrent claims, stale worker rejection, immutable freeze, completion after restart, authorized deletion, and expiry.
- [ ] HTTP tests prove schema rejection, wrong-token isolation, body limits, catalogue response, 202 submission, polling, and 204 deletion.
- [ ] A process restart preserves the submitted job. In-memory tests alone do not pass this card.
