# F2. Implement global globe search and field selection

Owner: @Quantomz
Lane: Frontend
Estimated effort: 2 hours. This is an estimate, not a delivery guarantee.
Phase: core

## Outcome

A farmer can find a location worldwide and mark their field, with usable coordinate controls when the globe or search is unavailable.

## Start immediately

Start from the [shared starter in PR #17](https://github.com/Quantomz/nefalos_nasa_hackathon/pull/17), branch `chore/parallel-build-baseline`. Use the checkout commands in its README. After that PR merges, new cards can branch from `main`.

Implementation prerequisites: None after the published shared baseline. Do not wait for another coding card.

Use `FieldPickerProps`, `inputFixture.field`, and `/dev/fixtures`. The picker receives only a field value and onChange. It needs no backend job, crop data, or onboarding implementation.

Read [AGENTS.md](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/AGENTS.md), activate pstack, and use the frozen [contracts](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/docs/contracts.md). The [specification](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/spec.md) owns product behavior.

## Implement

- [ ] Use the installed MapLibre GL JS globe projection. Use a configured MapTiler public browser key from `NEXT_PUBLIC_MAPTILER_KEY` for tiles/search, with provider attribution. Search submits explicitly rather than generating a request on every keystroke.
- [ ] Draw and edit one closed contiguous field polygon. Emit longitude-latitude vertices and an interior lookup point. Use the installed Turf helpers. Keep field-area labeling approximate.
- [ ] Normalize dateline-crossing input and support concave fields. Display source location precision without suggesting weather becomes field-resolution.
- [ ] Add a 2D fallback and accessible coordinate/vertex controls. Missing key, search failure, or unavailable WebGL must produce usable controls and a visible explanation.
- [ ] Keep provider access inside the location module; no database or calculation imports.

## Done when

- [ ] Browser checks select a normal field, concave field, and a dateline fixture with an inside lookup point.
- [ ] Globe rotation, submitted place search, zoom, polygon edit, and fallback controls work in a real configured browser. A mocked search alone does not pass that live criterion.
- [ ] No key is required to run component tests or coordinate input. Public attribution is visible.
