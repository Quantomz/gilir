## Implement

- [ ] Implement FAO-56 ET0, documented vapor-pressure/radiation conversions, Kc stage interpolation, and ETc exactly as spec section 5 defines. Missing required inputs remain unavailable.
- [ ] Build one common replay cohort from actual consecutive UTC dates. Target 25 seasons and require 15 complete seasons under default settings. Respect cross-year and February 29 rules. Optional imagery never reduces the core cohort.
- [ ] Compute rolling seven-day rain-demand F and M, zero-demand exclusion, and worst-crop annual aggregation. Compute supported stage-specific heat/cold exposure and nearest-rank quantiles.
- [ ] Compute scheduled occupancy/gaps, descriptive legume/family counts, and reviewed rule breaches/shortfalls. Unknown predecessors or host relationships never become zero risk.
- [ ] Return exact priority tuple components, per-season metrics, warnings, and unassessed checks. Bad-year temperature requirements and pest-coverage requirements fail closed.
- [ ] Implement historical monthly rainfall/temp/dry-spell insights with actual denominators and coverage. Label empirical frequencies and screening proxies correctly.

## Done when

- [ ] FAO reference examples and hand-worked rain windows match expected values with documented numerical tolerance.
- [ ] Tests cover zero demand, missing days, leap/cross-year replay, short crops, stage-specific heat, worst-crop aggregation, and nearest-rank quantiles.
- [ ] Changing only backup-water answer does not change supply or scores. Repeating a wet crop cannot dilute a dry crop through averaging.
- [ ] No runtime network, random source, wall-clock input, React, or database import enters the engine.
