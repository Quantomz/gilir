## Outcome

Retrieve NASA climate history and preserve data quality.

## Start immediately

Implementation prerequisites: None after the published shared baseline. Do not wait for another coding card.

Implement `prepareClimate({input,cutoff,settings,cache})` and its ClimateCache adapter. Use an injected in-memory cache and captured provider responses for independent development. B1 persistence is not a coding prerequisite. B3 supplies runtime cache composition.

Read [AGENTS.md](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/main/AGENTS.md), activate pstack, and use the frozen [contracts](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/main/docs/contracts.md). ## Implement

- [ ] Fetch UTC daily POWER meteorology and IMERG rain for the historical interval required by the fixed cutoff, the planning-year length, and permitted lookback. Request T2M, T2M_MIN, T2M_MAX, RH2M, WS2M, ALLSKY_SFC_SW_DWN, PS, and IMERG_PRECTOT.
- [ ] Normalize to the concrete units in ClimateSnapshot. Convert radiation/pressure according to the response metadata. Missing markers remain unavailable values. Reject duplicate dates and corrupt units.
- [ ] Record provider, product, stream/version availability, native cell/grid, original units, canonical units, conversion version, source URLs, retrieval time, and content hashes. Return unavailable for genuine missing coverage and failed with ServiceFailure for provider errors. Preserve partial snapshots in both branches.
- [ ] Key caches by native product cell, fields, product version, date range, and UTC. Avoid refetching the same native cell for neighboring points. Respect provider request limits and bounded retry/backoff.
- [ ] Keep different native grids explicit. Do not stitch ERA5 into isolated missing NASA days or invent stream metadata. Fetch failures never return synthetic climate as real data.
- [ ] Add a reproducible CLI that records source period and coverage without publishing private farm inputs. E2 owns cohort calculation and scientific ET0.

## Done when

- [ ] Fixtures verify missing-value markers, unit conversion, date duplicates, provider errors, source metadata, and cache reuse across points in the same cell.
- [ ] A real full-period retrieval is saved and its actual complete-season potential reported for a location with NASA coverage. A seven-day sample does not satisfy this criterion.
- [ ] A second-hemisphere location and a cross-year interval are fetched or honestly recorded as blocked. The worldwide adapter has no Java or country allowlist.
