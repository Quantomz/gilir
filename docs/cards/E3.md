## Outcome

The engine selects one reproducible rotation under the fixed water-first ranking, keeps every selected crop, and explains its ranking or why no plan is returned.

## Start immediately

Start from the [shared starter in PR #17](https://github.com/Quantomz/nefalos_nasa_hackathon/pull/17), branch `chore/parallel-build-baseline`. Use the checkout commands in its README. After that PR merges, new cards can branch from `main`.

Implementation prerequisites: None after the published shared baseline. Do not wait for another coding card.

Use `calculate(run,registry,options)` with injected `assess`, `buildCohort`, and `resolveRegistry` functions, and direct findCalendar/rankCandidates tests. This permits search and result implementation before E2 exists. Synthetic registry and climate fixtures supply all fields before E1/B2 finish.

`buildCohort` supplies required `applicabilityClimate` evidence using `RegistryLookup["climate"]`. E3 forwards it unchanged to `resolveRegistry`. E2 owns its annual aggregation, method version, and unavailable reasons. Direct `findCalendar` calls supply `initialPredecessor`, with null for unknown history. Waiting and recorded fallow preserve a known predecessor.

`buildCohort` also supplies required `elevationM` as `EvidenceValue<number>`. E3 forwards it unchanged to `assessClimate` and supplies latitude from the frozen field lookup coordinate. E2 owns provider-elevation selection across the product snapshots, unavailable reasons, and the selection method version in cohort metadata.

Direct `rankCandidates` calls supply the frozen integer `rankingDecimalPlaces` from 0 through 12. Compare with `Number(value.toFixed(rankingDecimalPlaces))`. Pass the selected result's `RankingDecision` to `explainResult`, or null without a selected candidate. The decision identifies the final runner-up and the actual deciding flag, metric, or tie rule.

Read [AGENTS.md](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/AGENTS.md), activate pstack, and use the frozen [contracts](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/docs/contracts.md). ## Implement

- [ ] Implement half-open one-calendar-year horizon, crop occupancy and turnaround, mandatory inclusion of every selected crop-purpose, repeats, no overlaps, and no unselected substitutions.
- [ ] Evaluate an eligible whole-sequence baseline independently. Preserve supported durations; unsupported or approximate history is labeled accurately. Unknown history does not block a new plan but suppresses its comparison.
- [ ] Implement daily structural witness/proof search with memoized complete state, safe lower-bound pruning, and fixed operation budgets. A grid miss or budget stop never proves impossibility.
- [ ] Enumerate the documented weekly-plus-edge candidate dates in stable order. Seed the baseline/witness. Count every opened ranking prefix against `gridExpansionLimit` and every additional unique complete assessment against `scoredCandidateLimit`. Seeds consume neither additional budget. Use E2 assessments via the injected interface and apply flagged-pool choice, lexicographic tuples, baseline preference, fewer occurrences, and canonical tie order.
- [ ] Return one of the six defined states. Show the best assessed warning arrangement when all are flagged. Missing ranking metrics return no plan. Return limited-search disclosure with a valid incumbent.
- [ ] Record `search.ranking = "interrupted"` when missing required evidence or a dependency or processing failure stops a started ranking traversal. Preserve actual grid and scoring counters. Reserve `limit_reached` and `search_limit` warnings for an actual operation-budget stop with pending work. Interruptions normally accompany `insufficient_data` or `service_error`.
- [ ] Generate deterministic reasons from actual score differences, source-backed preparation, and baseline crop/date matching. No LLM and no invented outcome claims.

## Done when

- [ ] Tests prove all-crop inclusion, repeats, impossible duration proof, a feasible daily witness absent from the weekly grid, and both budget-expiry cases.
- [ ] Each tuple position (frequency, mismatch, unplanted days, longest gap) has an explicit winning-candidate fixture, plus a full-tie test. An eligible current rotation can win. All-warning and missing-evidence cases remain distinct.
- [ ] Same frozen inputs produce the same semantic result across repeated runs, including explanations. Search limits count operations. Exact-limit exhaustion is complete when no work remains. Zero grid or scoring budgets preserve eligible assessed seeds. Report grid-prefix work independently in `SearchCoverage`.
- [ ] Interrupted ranking tests preserve partial grid and scoring counts and the evidence or service failure state. Elevation evidence passes unchanged from the injected cohort to assessment with the frozen field lookup latitude.
- [ ] Baseline skipped/unsupported/approximate/kept/changed cases render accurate structured explanations for F3.
