# E3. Generate and rank one valid rotation with reproducible explanations

Owner: @yslee1106
Lane: Calculations and crop data
Estimated effort: 3 hours. This is an estimate, not a delivery guarantee.
Phase: core

## Outcome

The engine selects one reproducible rotation under the fixed water-first ranking, keeps every selected crop, and explains its ranking or why no plan is returned.

Start from the [shared starter in PR #17](https://github.com/Quantomz/nefalos_nasa_hackathon/pull/17), branch `chore/parallel-build-baseline`. Use the checkout commands in its README. After that PR merges, new cards can branch from `main`.

Read [AGENTS.md](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/AGENTS.md), activate pstack, and use the frozen [contracts](https://github.com/Quantomz/nefalos_nasa_hackathon/blob/chore/parallel-build-baseline/docs/contracts.md). ## Implement

- [ ] Implement half-open one-calendar-year horizon, crop occupancy and turnaround, mandatory inclusion of every selected crop-purpose, repeats, no overlaps, and no unselected substitutions.
- [ ] Evaluate an eligible whole-sequence baseline independently. Preserve supported durations; unsupported or approximate history is labeled accurately. Unknown history does not block a new plan but suppresses its comparison.
- [ ] Implement daily structural witness/proof search with memoized complete state, safe lower-bound pruning, and fixed operation budgets. A grid miss or budget stop never proves impossibility.
- [ ] Enumerate the documented weekly-plus-edge candidate dates in stable order. Seed the baseline/witness. Use E2 assessments via the injected interface and apply flagged-pool choice, lexicographic tuples, baseline preference, fewer occurrences, and canonical tie order.
- [ ] Return one of the six defined states. Show the best assessed warning arrangement when all are flagged. Missing ranking metrics return no plan. Return limited-search disclosure with a valid incumbent.
- [ ] Generate deterministic reasons from actual score differences, source-backed preparation, and baseline crop/date matching. No LLM and no invented outcome claims.

## Done when

- [ ] Tests prove all-crop inclusion, repeats, impossible duration proof, a feasible daily witness absent from the weekly grid, and both budget-expiry cases.
- [ ] Each tuple position (frequency, mismatch, unplanted days, longest gap) has an explicit winning-candidate fixture, plus a full-tie test. An eligible current rotation can win. All-warning and missing-evidence cases remain distinct.
- [ ] Same frozen inputs produce the same semantic result across repeated runs, including explanations. Search limits count operations rather than time.
- [ ] Baseline skipped/unsupported/approximate/kept/changed cases render accurate structured explanations for F3.
