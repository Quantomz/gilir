# F2 MapTiler logo verification

The picker now displays the official linked MapTiler logo when a browser key is configured. Its dark plate keeps the white lettering readable in both themes. The text credits remain visible. A build without a key keeps the coordinate controls and omits the provider logo.

The owner approved this narrow F2 change after confirming a Free account. [MapTiler's attribution guide](https://docs.maptiler.com/guides/map-design/attribution/add-attribution/) requires a linked logo for that plan. The unchanged SVG came from `https://api.maptiler.com/resources/logo.svg`. Its SHA-256 is `c2fef38a1e77e9ff774dc1b21a2e931c81eab12191395be726c594404e4bf332`.

## Regression and fix

The first logo placement made the drawing label cover corner 1 when WebGL was unavailable. The fallback now gives the drawing its existing responsive height and places the footer below it. The globe keeps its overlay footer. Browser assertions compare all four corner-number rectangles with the footer and scale label at 360 and 1280 pixels.

The [before log](logo-2026-11-15/fallback-before.log) reports `2 failed`, including `corner 1 must not overlap the fallback footer`. The [after log](logo-2026-11-15/fallback-after.log) reports `2 passed`. An initial implementation used local CSS variables, which failed the existing F2 convention test. The final implementation shares the sizing rules through grouped selectors and passes that rule without changing the test.
